# Expeditor Tracker

Общий кабинет диспетчеров: задачи, фильтры, карта Астаны и обновления Socket.IO. Все авторизованные диспетчеры имеют доступ ко всем задачам. Создание пользователей выполняет администратор через CLI.

**[План реализации и критерии готовности](IMPLEMENTATION_PLAN.md).** Исторический отчёт: [REPORT.markdown](REPORT.markdown).

## Требования

Python 3.11, PostgreSQL 16, Node.js 22 для JS-тестов и необязательной сборки CSS. Один процесс API: доставка Socket.IO между несколькими workers пока не реализована.

## Установка (PowerShell)

```powershell
git clone https://github.com/amanchiqq/expeditor-tracker.git
cd expeditor-tracker
python -m venv .venv
.venv/Scripts/Activate.ps1
python -m pip install -r requirements-dev.txt
```

Создайте отдельную базу PostgreSQL и пользователя с правами на неё. Приложение не создаёт сервер БД. Затем задайте переменные в текущем терминале:

```powershell
$env:SECRET_KEY = python -c "import secrets; print(secrets.token_urlsafe(48))"
$env:DATABASE_URL = 'postgresql://tracker:YOUR_PASSWORD@localhost:5432/expeditor_db'
$env:CORS_ORIGINS = 'http://localhost:8080,http://127.0.0.1:8080'
python scripts/migrate.py
python scripts/create_user.py
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

Пароль вводится скрыто; стандартного аккаунта/пароля нет. Для постоянного окружения сохраните секрет в менеджере секретов или настройках сервиса: новая генерация при каждом запуске аннулирует прежние JWT. Файл .env.example описывает переменные; автоматической загрузки .env нет. Для Bash используйте export вместо синтаксиса PowerShell.

## Интерфейс

В другом терминале из папки проекта:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Откройте http://localhost:8080. index.html ведёт на dashboard.html, без токена выполняется переход на login.html. Успешный вход действует 30 минут; истёкшая сессия требует повторного входа.

Карта работает на MapLibre GL JS 6.16.0 + OpenFreeMap. Регистрация у поставщика карты, банковская карта и API-ключ не нужны. В frontend-config.js находятся только apiBase и mapStyleUrl. По умолчанию API использует хост страницы и порт 8000; для другого сервера измените apiBase и CORS origins. MapLibre JS/CSS загружаются с UNPKG, данные карты — с OpenFreeMap; требуется интернет и браузер с WebGL.

Выберите точку кликом по карте или перетащите зелёную метку, затем нажмите Add Task: координаты попадут в форму. Координаты также можно ввести вручную. Синие метки обозначают задачи текущей страницы, нажатие показывает описание безопасным текстом. Обновление списка задач сохраняет выбранную зелёную точку. Clear Map очищает метки и выбор; Refresh снова загружает метки задач.

OpenFreeMap разрешает коммерческое использование без ключей и лимитов просмотров по опубликованным условиям, но не предоставляет SLA. Не скрывайте атрибуцию OpenStreetMap/OpenMapTiles: MapLibre показывает её автоматически из стиля. Условия: https://openfreemap.org/ . URL стиля можно заменить в конфигурации. Если внешний сервис или WebGL недоступен, таблица и ручной ввод координат продолжают работать.

Поиск адресов теперь доступен через Photon без регистрации и API-ключа. Введите название места или адрес в районе Астаны, нажмите «Найти адрес» и выберите результат. Проверьте найденную точку: полнота и точность зависят от OpenStreetMap. Координаты и подпись попадут в новую задачу; их можно исправить. Маршрутизация пока не подключена.

Поиск выполняется сервером только после явного нажатия, без автодополнения при наборе. Запрос адреса передаётся публичному Photon. Не включайте имена клиентов, телефоны или другую частную информацию в запрос. Кэш в памяти хранит до 128 результатов поиска 5 минут, включая пустые результаты. Для некэшированных запросов установлены собственные консервативные ограничения: не чаще одного внешнего обращения в 1,1 секунды на процесс и до 10 обращений в минуту на диспетчера; одновременный новый поиск получает 429. Это ограничения приложения, а не гарантированная квота провайдера.

Публичный Photon допускает умеренное использование, может ограничить нагрузку и не даёт SLA: https://github.com/komoot/photon#demo-server . Для большей нагрузки используйте собственный или другой согласованный Photon-совместимый сервер через PHOTON_API_URL в окружении API. Адрес endpoint задаёт администратор, не пользователь запроса. Таймаут внешнего запроса — 5 секунд. При недоступности поиска остаются карта и ручные координаты. Вход в сам кабинет диспетчера по-прежнему обязателен: отсутствие регистрации относится к поставщику карты.

Таблица отображает текущую страницу; диаграмма и показатели исполнителей/статусов — все задачи текущего фильтра, без демонстрационных чисел. Фильтр исполнителя сочетается с остальными фильтрами. Время задач показывается в часовом поясе браузера, указанном над таблицей; фильтр даты по-прежнему использует UTC. Начальный центр карты — Астана; отображаются все задачи текущей страницы с валидными координатами, без прежнего ограничения прямоугольником города. Реального источника геолокации и расчёта маршрутов пока нет.

## Даты и API

- POST /token — form-urlencoded username/password.
- GET /geocode?q=... — авторизованный поиск адреса/места в районе Астаны; 3…200 символов, до 5 результатов, 429 при ограничении и 503 при недоступном провайдере.
- GET /tasks — task_id, expeditor_id, status, date (YYYY-MM-DD, UTC), page >= 1, per_page 1…100.
- GET /tasks/{id}, POST /tasks, PUT /tasks/{id}, DELETE /tasks/{id} — Bearer JWT.
- status: in_progress или completed; expeditor_id > 0; description до 255 символов.
- latitude/longitude либо обе отсутствуют, либо обе заданы в допустимых диапазонах.
- eta: null или ISO datetime с часовым поясом. Интерфейс переводит локальный ввод в UTC.
- PUT полностью заменяет редактируемые поля; это не PATCH.
- /docs — описание HTTP API.

Socket.IO: path /socket.io, auth: {token: JWT}. Сервер публикует tasks_changed с action и task_id только в комнату авторизованных диспетчеров после успешной записи. Клиент перечитывает /tasks после события и reconnect. Нотификации не имеют гарантии доставки; ошибка отправки не отменяет уже выполненный CRUD. Синтетический location_update удалён. Изменения напрямую в БД уведомлений не создают.

## Миграции существующей базы

До запуска сделайте backup. 001_dispatcher_schema.sql поддерживает пустую БД и схему из прежнего README: добавляет status/eta, ограничения и индексы. Прежний TIMESTAMP без timezone интерпретируется как UTC. Если раньше хранилось местное время, сначала согласуйте преобразование на копии БД. Нестандартные схемы необходимо проверить отдельно.

Миграции транзакционные, применяются один раз под advisory lock, проверяют контрольную сумму. Повторный запуск безопасен. Некорректные старые записи могут нарушить новые ограничения: миграция откатится, данные автоматически не удаляются. Исправьте записи на копии и повторите проверку. Уже применённые миграции не редактируют; добавляют следующую.

## Тесты

```powershell
python -m pytest -q
node --test tests/frontend.test.cjs
```

Для настоящих интеграционных проверок задайте отдельную тестовую БД:

```powershell
$env:TEST_DATABASE_URL = 'postgresql://tracker:TEST_PASSWORD@localhost:5432/tracker_test'
python -m pytest -q
```

Интеграционные тесты создают уникальную временную схему и удаляют её после проверки; пользователь тестовой БД должен иметь право CREATE SCHEMA. Не используйте рабочую БД. Без TEST_DATABASE_URL эти две проверки явно пропускаются. GitHub Actions поднимает PostgreSQL и запускает их вместе с остальными тестами.

Локально проверены API с подменённой БД, валидация, JWT, ошибки, освобождение подключений, handshake/auth/event Socket.IO через ASGI и JS-контракты. Основа API проверена в GitHub Actions на PostgreSQL 16: 54 Python-теста, включая пустую и прежнюю схемы БД. Набор JS-проверок расширен тестами бесплатной карты. Браузерный E2E требует отдельной приёмки согласно плану.

Для разработки CSS (не требуется для Python API): npm ci, npm run build:css или npm run watch:css. node_modules не хранится в Git.

## Проверка карты без базы данных

После запуска статического сервера откройте http://localhost:8080/tests/map-preview.html . Страница показывает карту Астаны и демонстрационные задачи без API и логина. Проверьте клик, перетаскивание зелёной метки, обновление задач и очистку выбора. На ней выполнена браузерная проверка загрузки настоящей карты и сохранения выбранных координат после обновления задач; это не полный E2E с PostgreSQL.

## Автоматическая браузерная приёмка

GitHub Actions устанавливает Chromium и запускает tests/test_browser.py: два изолированных кабинета, настоящий API, PostgreSQL и Socket.IO. Проверяются вход, поиск и его ошибки, создание/редактирование/удаление, XSS-вывод, фильтр исполнителя, пагинация и обновления второй вкладки. Внешние карта и Photon подменены, поэтому этот тест не расходует публичные квоты и не доказывает качество адресной базы. Настоящая карта ранее проверена отдельно, Photon проверен запросом к общеизвестному объекту Астаны.

Для локального запуска с отдельной тестовой БД установите requirements-browser.txt, выполните python -m playwright install chromium и npm install --no-save --ignore-scripts --package-lock=false socket.io-client@4.7.5, задайте TEST_DATABASE_URL и RUN_BROWSER_E2E=1, затем python -m pytest tests/test_browser.py -q -s. Тест создаёт/удаляет уникальную схему, запускает серверы на loopback и не использует рабочую базу. Скриншоты и traces сохраняются в test-results/ и публикуются как browser-proof в CI.
