# План реализации Expeditor Tracker

Обновлён: 28 октября 2026.

## Продукт и границы

Общий кабинет диспетчеров: каждый авторизованный диспетчер видит и изменяет все задачи. Это подтверждено владельцем проекта. Публичной регистрации и личного кабинета экспедитора на текущем этапе нет. Диспетчера создаёт администратор через CLI.

Исходный план находится в REPORT.markdown и прежних версиях README: геокодинг, точки на карте, геолокация, маршруты, админка, полноценный real-time. Старые отметки о выполнении не являются результатами автоматизированной проверки. Этот файл задаёт актуальную последовательность и критерии приёмки.

Стек: модульный монолит FastAPI + asyncpg/PostgreSQL + обычный JavaScript + Socket.IO. Микросервисы, новый frontend framework и брокер событий пока не требуются.

## Правила реализации

Каждый этап завершается проверяемым результатом и обновлением этого файла. Не отмечать интеграции и браузерные сценарии как выполненные по одним unit-тестам. Развёртывание и миграции рабочей БД выполняются отдельно после проверки резервной копии и часового пояса прежних данных.
